# CAKEPANO

A responsive bakery website built with HTML5 and CSS3 as a university web development project.

## Live Website

[Visit CAKEPANO](https://people.arcada.fi/~chelpand/webdev/cakepano-project/CAKEPANO/)

## About the Project

CAKEPANO is a minimalist website for a handmade home bakery. The design focuses on warm colours, simple typography, large images and a personal handmade feeling.

The website includes:
- Home page
- Menu
- My Work gallery
- About page
- Order form
- Web Report

## Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive design
- SVG
- HTML5 video
- HTML5 audio
- iframe gallery
- OpenStreetMap

## Features

- Responsive layout for desktop, tablet and mobile
- Responsive images using the `<picture>` element
- Image gallery with thumbnails
- CSS animation
- HTML5 video and audio
- Order form
- Embedded map
- Semantic HTML5 structure

## University Project

This project was created as part of a web development course at Arcada University of Applied Sciences.
